# Navigation (phase 36)

Cinq espaces remplacent les sept onglets : **Structure**, **Sons**, **Mix**, **Live**, **Plus**. Le **Mode simple** en a quatre : **Mon morceau**, **Rythme**, **Clavier**, **Envoyer**. Le mode se choisit au premier lancement et dans Plus › Réglages ; changer de mode ne touche jamais au projet (seul l'affichage change).

Ce qui ne bouge pas, sur tous les espaces : la barre du haut (projet, partie, ↶, ●, ▶, ⤴), le bandeau de lecture (tempo, position, « ⟳ Partie ») et, nouveau, le « ? » qui étiquette l'écran au bout de ce bandeau.

## Nouveaux gestes

- **Structure, ligne du temps** : toucher un bloc coupe ou remet la piste dans cette partie (inchangé) ; **deux touches sur un bloc** l'ouvrent dans Sons, sur la bonne piste et la bonne partie ; **toucher le nom d'une piste** ouvre « Changer le son » (le kit pour la batterie, les sons de la 303, la feuille d'un instrument, la page Voix pour une piste audio) ; **appui long sur un drapeau** de partie ouvre sa feuille (Fill, Break, Montée, Fondu, Fin…) ; appui long puis glisser la déplace (inchangé).
- **Sons** rouvre le dernier éditeur ouvert (gardé sur le téléphone).
- **« ? »** au bout du bandeau de lecture : un toucher pose une étiquette sur les commandes principales de l'écran, un autre les enlève (« Masquer les étiquettes » aussi).
- **« Mon premier morceau »** (Plus, Plus › Aide, « Que veux-tu faire ? » ou le premier lancement « guidé ») : depuis G5, les premières cartes du Guide (« Pour commencer ») : choisir un style, écouter (« Ton morceau est prêt »), changer un son, enregistrer une mélodie, arranger, puis le parcours jusqu'au partage et au Remix. Une carte se coche toute seule quand c'est fait ; on peut la sauter ; tout est gardé dans le projet.

## Ce qui est gardé à la reprise

- L'écran ouvert, la page de Plus, la vue de Structure, les étiquettes : sauvés avec l'activité (rotation, mort du processus).
- Le dernier éditeur de Sons et la vue de Structure : aussi sur le téléphone (préférences « nav »).
- Les missions : préférences « missions » (étape, point de départ, étapes passées).
- L'appli n'a pas de lien profond en dehors de son lancement (MAIN) : rien d'autre à reprendre.
