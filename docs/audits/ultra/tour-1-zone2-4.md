## Vérifications
- `scripts/host-tests.sh` : tous les tests passent (5 min), dont le nouveau `mp_club_and_streaming_exports_differ`.
- Tests ciblés : `OneTargetExportTest`, `ExportResultInViewTest`, `RecordZone4Test`, `MasterProFreeTargetTest`, `WavExporterTest`, `OneLoudnessTargetTest`, `LoudnessTargetTest`, `I18nCatalogTest` (aucune clé manquante de nos fichiers ; 28 chaînes dans les 14 langues, `ultra1_export.json`), navigation, aide, enregistrement, exports : verts.
- `SimpleModeAuditTest` : 2 échecs (`theKeysHaveNoExpertTools`, `theKeysAreAboveTheGuidesBarAt130`) présents aussi sans nos changements de la barre d'enregistrement : à voir avec les autres équipes.
- Banc de morceaux non relancé : Auto et Club envoient au moteur les mêmes commandes qu'avant (seul Streaming change de mode), le moteur n'est pas modifié.
