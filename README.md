# BenStudio

Appli Android de création de musique électronique : boîte à rythmes, sampler, synthés, remix par séparation de pistes.
Usage personnel, installation directe par APK (pas de Play Store).

## Installer

1. Sur le téléphone, ouvre ce lien (mets-le en favori sur l'écran d'accueil) :
   **https://github.com/benjaminpaquot123-netizen/pocket-studio/releases/latest/download/pocket-studio.apk**
2. Ouvre le fichier téléchargé. Android demande d'autoriser l'installation depuis le navigateur : accepte pour cette source uniquement.
3. Ensuite l'appli se met à jour toute seule : au lancement, elle propose la nouvelle version, un geste et c'est installé par-dessus, projets conservés.

### Version d'aperçu (pour tester une phase avant de la valider)
**https://github.com/benjaminpaquot123-netizen/pocket-studio/releases/download/preview/pocket-studio-preview.apk**
Elle s'installe par-dessus la version stable, sans rien perdre.

## Tester et signaler
- Onglet **Recette** : coche ✅ ou ❌ chaque vérification, puis « Envoyer le rapport ». GitHub s'ouvre avec le rapport déjà rédigé : appuie sur *Submit new issue*.
- « Signaler un problème » : une phrase suffit, l'appli joint la version, l'appareil, la latence et le journal.
- Si l'appli plante, elle propose d'envoyer le rapport au lancement suivant.

## Réglages conseillés (MagicOS / HyperOS)
- **Batterie** : Réglages → Batterie → Lancement des applis → BenStudio → gestion manuelle, tout autoriser (sinon le système peut couper le son ou une séparation longue).
- **Casque** : pour jouer en direct, préfère un casque filaire USB-C ; le Bluetooth ajoute un retard audible.
